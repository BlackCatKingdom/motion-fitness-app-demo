# MOTION — Fitness Training App Concept

MOTION is an **Independent Concept Project** designed and developed by SEEKBLACK to demonstrate mobile product architecture, training-state management, data UI and an app-like web/PWA experience.

## Live Demo

https://motion.seekblack.cn/

## Case Study

https://seekblack.cn/work/motion/

## Product questions

MOTION is built around two simple user needs:

1. What should I do today?
2. How has my recent training been going?

## Main modules

- Onboarding
- Login demo
- Home
- Plan
- Training session
- Current-set countdown for time-based exercises
- Stats
- History
- Profile
- Metric / Imperial unit switching

## Training interaction

The training experience distinguishes between repetition-based and duration-based sets. Time-based sets such as `60 seconds` or `5 minutes` use an actual countdown, while repetition-based sets remain manual completion actions.

The demo also maintains consistent workout history, weekly progress and session state across navigation and reloads.

## Stack

- Semantic HTML
- CSS
- Vanilla JavaScript
- Browser local storage
- PWA manifest + service worker
- Responsive full-screen mobile mode

## Scope and safety

MOTION is a product-design and front-end interaction demonstration. It does not claim medical assessment, professional training prescription, AI coaching or healthcare capability.
